Student Profile App Using Flutter

Project Overview

This project is developed using Flutter and Dart as part of the CS506PC UI Design (Flutter Lab). It demonstrates UI design, responsive layouts, navigation between screens, state management, custom widgets, form validation, animations, REST API integration, and testing through a Student Profile application.

Technologies Used

- Flutter
- Dart
- Visual Studio Code
- REST API
- HTTP package
- Git and GitHub

How to Run the Project

1. Install Flutter and configure the development environment.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Install dependencies:

flutter pub get

5. Run the application:

flutter run

6. Run the widget tests:

flutter test

Conclusion

This project helped develop an understanding of Flutter widgets, responsive UI design, navigation, state management, custom components, form validation, animations, REST API integration, and widget testing. It demonstrates the development of a Student Profile application using Flutter and Dart.
